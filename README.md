# RadioBIM

Data for [radiobim.com](https://radiobim.com): a daily radar of LinkedIn posts about AI in AEC, MCP and AI agents, Revit/Navisworks add-ins, open source, courses, ideas and engineers' tools.

- `data.json` — every post (Arabic and English title/description, section, tags, author, date, LinkedIn link, tool link). Updated daily.
